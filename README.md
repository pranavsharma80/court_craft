# ⚖️ CourtCraft
## Courtroom Case Management & Priority System

CourtCraft is an educational project designed to organize pending court cases and prioritize them based on urgency. The system aims to calculate an urgency score for each case using factors such as case type, severity, waiting time, and special conditions.

The project demonstrates how **Data Structures and Algorithms (DSA)** and **Object-Oriented Programming (OOP)** can be applied to a practical case-management problem.

## 📌 Description

Managing pending court cases can be challenging when different cases require different levels of attention. CourtCraft explores a structured approach to case registration, searching, priority management, and hearing-history tracking.

The proposed system uses urgency-based prioritization to identify cases that may require earlier attention, making the simulated courtroom workflow more organized and efficient.

**Note:** CourtCraft is an educational simulation and does not represent official judicial rules or replace real court-management systems.

## ✨ Features

- Register and manage court cases
- Classify criminal, civil, and family cases
- Calculate urgency scores using selected factors
- Prioritize cases using a Priority Queue
- Search cases using a unique Case ID
- Maintain hearing history
- Organize evidence and witness information
- Track case status
- Explore undo functionality for recent operations

*Feature availability depends on the current implementation.*

## 🛠️ Technology Stack

- **C** – Case ID validation module
- **C++** – Case-management console prototype and OOP concepts
- **React** – Frontend interface
- **Vite** – Frontend development and build tooling
- **Tailwind CSS** – Interface styling
- **Data Structures and Algorithms** – Case searching and prioritization
- **Object-Oriented Programming** – Classes, inheritance, encapsulation, abstraction, and polymorphism

## 🧠 Data Structures Used

| Data Structure | Purpose |
|---|---|
| Priority Queue / Max-Heap | Organize cases by urgency |
| Hash Map | Search cases using Case ID |
| Linked List | Maintain hearing history |
| Stack | Support undo operations |

## 🏗️ Object-Oriented Programming

The proposed C++ design explores:

- **Classes and Objects:** Represent cases and the courtroom system.
- **Encapsulation:** Organize data and related operations.
- **Abstraction:** Simplify interactions with system components.
- **Inheritance:** Represent different case categories.
- **Polymorphism:** Support specialized behavior for different case types.
