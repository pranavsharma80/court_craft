# Courtroom Case Management & Priority System

## Description

The Courtroom Case Management & Priority System is designed to help manage and prioritize pending court cases efficiently. The system assigns an urgency score to each case based on different factors such as case type, age of the case, and priority level. This helps in identifying important cases that require earlier attention.

The project aims to make the case management process more organized and efficient by reducing delays and helping authorities schedule cases according to their urgency.

## Technology Stack

- C++
- Data Structures and Algorithms
- Object-Oriented Programming

## Features

- Add and manage court cases
- Assign priority based on urgency
- Organize cases efficiently
- Help identify urgent cases
